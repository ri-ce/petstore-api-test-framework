网页自动化测试

使用 Playwright 自动打开真实商城网页，模拟用户登录、浏览商品、排序、加入购物车 并完成结算，验证页面元素和业务流程是否符合预期。

查看 GitHub 源码 打开测试报告 访问被测网站
12网页自动化用例
100%最近一次通过率
19.40s本地执行耗时
3页面对象模块

覆盖完整购物流程

01正常登录、错误密码、锁定账号与退出
02商品数量、价格排序与名称排序
03购物车、表单校验与订单完成

测试使用真实浏览器执行，而不是只检查网页源代码或接口返回值。

技术要点

  • Playwright 浏览器自动化
  • Page Object 页面对象分层
  • 显式等待和稳定元素定位
  • 失败自动截图

本地运行

进入仓库目录后执行：

.\run_ui_tests.ps1

脚本会安装依赖并自动打开无头浏览器执行测试。

测试设计

  • 从核心购物路径拆解测试场景
  • 同时覆盖正常与异常流程
  • 使用业务结果断言，而非固定等待
  • 页面变化时集中修改页面对象
