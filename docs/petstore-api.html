框架技术要点

  • Pytest fixture 生成唯一 ID 与清理资源
  • Requests Session 统一封装请求
  • HTTPAdapter 提供超时与指数退避重试
  • GitHub Actions 自动执行完整回归

本地运行

进入仓库目录后执行：

.\run_tests.ps1

脚本会安装依赖并连接 Petstore V3 执行全部用例。

测试可靠性

  • 不依赖固定商品或订单 ID
  • 测试资源在结束后自动删除
  • 临时网络异常使用有限次重试
  • 业务断言失败不会被重试掩盖
